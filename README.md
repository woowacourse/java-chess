# java-chess

체스 미션 저장소

## 요구사항
- 킹(King)
  - 위, 아래, 양옆, 대각선 한 칸씩 이동
- 퀸(Queen)
  - 일직선으로 앞, 뒤, 옆, 대각선 어떤 방향이든 원하는 만큼 이동
  - 본인의 기물을 뚫고 갈 수 없음(같은 팀)
  - 상대방을 잡으면 종료됨
- 룩(Rook)
  - 원하는 만큼 앞, 뒤, 양옆으로 이동 가능
- 나이트(Knight)
  - 한 방향으로 두 칸을 이동하고 그와 90도를 이루는 방향
    - 전진 2칸 + 옆 1칸
    - 왼쪽 2칸 + 위 or 아래 1칸
    - 오른쪽 2칸 + 위 or 아래 1칸
    - 뒤 2칸 + 옆 1칸
  - 유일하게 중간에 기물이 있어도 뛰어넘을 수 있음
- 비숍(Bishop)
  - 원하는 만큼 대각선으로만 이동 가능
  - 한 개의 색깔에서 시작해 그 색으로만 다님
- 폰(Pawn)
  - 앞으로 1칸
  - 잡을 때는 대각선 1칸만 가능
  - 처음 움직이는 폰은 2칸 가능
